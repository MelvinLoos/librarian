# Frontend Agent Rules: Atomic Design & Reka UI

**Context:** This directory governs all `frontend/` work. The frontend is a Nuxt 4 + Vue 3 PWA styled with TailwindCSS and the Material Design 3 (MD3) tonal palette exposed as CSS custom properties in `assets/css/main.css`.

## 🔴 GLOBAL DIRECTIVES

1. **Atomic Design Hierarchy:** Components are organized strictly as:
   - **Atoms** (`components/ui/`): Domain-agnostic primitives (`UiButton`, `UiInput`, `UiSelect`, `UiCheckbox`, `UiTextarea`, `UiDialog`). ZERO imports from `domain/`, `stores/`, `infrastructure/`, or Bounded-Context components. No business vocabulary.
   - **Molecules** (`components/`): Combinations of atoms that MAY reference one Bounded Context (e.g. `UploadDropzone` is Storage; `BulkEditModal` is Catalog).
   - **Organisms / Pages** (`pages/`): Compose molecules and atoms into routes.
2. **Reka UI Conventions:** `reka-ui` (v2) provides *headless,* accessible Radix-style primitives (Dialog, Checkbox, Select, Button, etc.). Atoms MUST compose reka-ui primitives for behavior/a11y and apply MD3 theming via `tailwind-variants`. Atoms exposed to the rest of the app are the `Ui*` components.
3. **Tailwind Variants:** Every `Ui*` atom exports a typed `variants()` config (color/tone, size, state) generated by `tailwind-variants`. No hard-coded Tailwind class strings in consuming components where a variant exists.
4. **MD3 Theming Only:** All colors come from the existing token map (`bg-surface`, `text-on-surface`, `bg-primary`, `text-on-primary`, `outline`, `error`, etc.) already registered in `tailwind.config.ts`. Never introduce raw hex colors.
5. **Test Hooks:** Every interactive element exposes a `data-test` attribute so molecule specs can select atoms reliably.
6. **Testing:** Vitest + `@vue/test-utils`. Component specs live in `tests/components/**`. Adversarial TDD: failing spec log is posted to the GitHub issue BEFORE implementation.
7. **Bounded Contexts:** The UI is a delivery layer — it may call `infrastructure/api/*` clients but never import one Bounded Context's backend module from another. Domain types come from `domain/**`.
